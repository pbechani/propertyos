B — Dark Carbon Hero

Dark Carbon Hero

The image and key property data live in a dramatic carbon-dark hero section — matching the homepage dashboard panel aesthetic. The price and address display in white Fraunces against near-black. Below the hero, the tab content flips to warm parchment. Electric-green stats reinforce the premium trust signal. High contrast, editorial luxury.

C — Forest Command

Forest Command Centre

A commanding forest-green header band holds the page title, property image, price, specs, and agent badge — like a professional property management dashboard. The whole top third is forest-colored; parchment picks up below. Uses the same visual language as the sidebar. Tabs sit on the forest band with white/terracotta active state — the most "management tool" feeling of the three.

Recommended for Most conservative rebrand Maximum visual impact Cohesion with overall app chrome
Notes for all approaches
  • Every approach replaces bg-gray-50, border-gray-200, and text-blue-600 — the three main off-brand offenders
  • AI Assistant button becomes bg-forest text-egreen or border-egreen/30 text-egreen — no more indigo gradient
  • Status badge: bg-egreen text-carbon; Sale type badge: bg-terra text-white
  • SectionCard icons: text-[#1A3C28] (forest) instead of text-blue-600; section header strip: bg-forest/4 instead of bg-gray-50/70
  • All heading text switches to font-fraunces via style{{fontFamily:'var(--font-fraunces)'}}
  • OverflowTabBar overflow dropdown: dark card bg-forest text-white rather than generic popover
