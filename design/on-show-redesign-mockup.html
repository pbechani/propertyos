④ Design Decisions
1
Query-param tabs
Tab state stored in URL as ?tab=dashboard so deep-links work perfectly and browser back/forward navigation moves between tabs without page reload.
2
Old routes → redirects
All 9 /app/open-houses/* pages become redirect() calls pointing to /app/on-show?tab=*. Existing external links and bookmarks continue to work.
3
Forest header parity
Same forest header block, decorative circles, IBM Plex Mono eyebrow, Fraunces h1, and parchment subtitle as My Listings and the newly redesigned My Calendar.
4
5-cell KPI strip
Active Properties (egreen), Events This Week (parchment), Leads Captured (gold), Active Workflows (parchment), Pending Tasks (amber) — all computed from existing view data.
5
Sidebar cleanup
Remove showOpenHouses state, openHousesNavigation array, and the toggle button. Replace with a single flat Link to /app/on-show.
6
"Open Houses" → "On Show"
The tab that was "Open Houses" inside the events section becomes "On Show". The tab within OHOpenHousesView changes its label — any reference in that view saying "Open Houses" becomes "On Show".
