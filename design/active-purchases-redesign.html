Design Notes

What's Being Solved

The current tab shows only a "Coming Soon" card — but we already have offer data from buyerOffersApi.list(). Offers = the start of the purchase pipeline. We can show real, actionable data now.

Gaps Identified

Gap No purchase pipeline API (Sprint 04)
Gap BuyerOfferResponse has no property title/image
Gap No counter-offer endpoint yet
Gap No conveyancer assignment API
Gap Stage transitions not tracked

Fix Use buyerOffersApi.list() + propertiesApi.getById() to hydrate property details
Fix Map offer statuses → pipeline stage numbers
Fix Show "stage X of 14" derived from offer status

New Features Added

  • Stats strip (count, total committed, escrow)
  • Filter pills by pipeline phase
  • "Action Needed" alert badge
  • Offer status banner with CTA
  • Next Step indicator
  • Stage checklist (expandable)
  • 14-stage visual pipeline
  • Key contacts panel
  • Financial summary per purchase
  • Empty state with clear onboarding CTA

Data Strategy (Sprint 03)

Since full pipeline API is Sprint 04, this sprint can:

  • Show offers as Stage 2 (submitted) or Stage 3 (countered)
  • Hydrate property details via a second API call
  • Lock Stage 4–14 as "upcoming" until Sprint 04
  • Pipeline strip shows full 14 stages visually

Sprint Scope

Sprint 03 Stats strip, cards with offer status, filter bar, empty state

Sprint 04 Full 14-stage pipeline, checklist, document uploads, conveyancer
