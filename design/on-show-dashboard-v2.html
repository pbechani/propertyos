Design rationale & key decisions
A
Live Now banner — terracotta-toned strip that appears when an event is in progress. Shows attendee count, property, and time remaining. Includes a progress bar for elapsed duration. Dismissible.
B
KPI strip unified — Header strip now connected to the same data hook as the dashboard metrics. The duplicate "Key Metrics" section below was removed to prevent data redundancy. Sparklines show 4-week trends.
C
Event cards with thumb — Each card has a color-gradient property image block, an address overlay, a status badge (Live / Today / Thu), lead count badge, and attendee stats. Click navigates to event detail.
D
Countdown in timeline — Forest-green chip above the timeline shows "Next Event In" with live countdown. Urgency without noise — only appears if the next event is within 4 hours.
E
Brand palette everywhere — Forest for primary, Terracotta for CTAs/alerts, Egreen for success/live, Amber for warnings, Parchment for surfaces. Slate/gray completely purged from this tab.
F
Typography — Fraunces for all metric numbers and section headings (already used in header, now extended to content area). IBM Plex Mono for all labels, eyebrows, meta text. IBM Plex Sans for body.
