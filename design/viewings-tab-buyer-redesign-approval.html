DESIGN NOTES
① Live badge count
The Viewings tab now shows a live count badge (3 = upcoming + pending). Fetched via viewingsApi.getMyViewings() on mount.
② Timeline grouping
Viewings are grouped by date proximity: Today, Tomorrow, This Week, Next Week, Later — with collapsible past section.
③ Status stripe + badge
Left-edge colour stripe (green=confirmed, amber=pending, grey=past, red=declined) + text badge for clear scanning.
④ Buyer actions
Confirmed → Reschedule + Cancel. Pending → Cancel Request only. Completed → View Property + Feedback prompt. Declined → Re-request.
⑤ Filter + sort bar
Filter by status (All / Upcoming / Pending / Completed) and by type (In-Person / Virtual). Sort by soonest or latest.
⑥ Feedback banner
Completed viewings with no feedback show a subtle in-card prompt. Dismissed once feedback is submitted via existing agent-feedback endpoint.
