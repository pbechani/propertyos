## Gaps Found and Status

- **Issue:** Multiple controllers used `req.user.roles?.[0]` to infer actor role, which can break admin override if role order is not admin-first.
- **Risk:** Incorrect authorization behavior for multi-role users.
- **Status:** ✅ Fixed
- **Files updated:**
  - `apps/api/src/property/property.constants.ts`
  - `apps/api/src/property/property.controller.ts`
  - `apps/api/src/property/verification.controller.ts`
  - `apps/api/src/property/buyer.controller.ts`
  - `apps/api/src/property/fraud.controller.ts`

### 2) SEO acceptance criteria incomplete on listing detail page
- **Issue:** Dynamic listing route lacked route-level SSR metadata + structured data implementation.
- **Risk:** Misses Sprint 03 SEO acceptance criterion (title/meta/OG/schema/canonical).
- **Status:** ✅ Fixed
- **File updated:**
  - `apps/web/src/app/properties/[id]/page.tsx`
- **Implemented:**
  - `generateMetadata()` with title/description/openGraph/canonical
  - schema.org `RealEstateListing` JSON-LD

### 3) Missing property API client surface in web layer
